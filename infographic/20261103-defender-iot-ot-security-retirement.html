📋 概要

Microsoft は、Microsoft Defender for IoT の OT (Operational Technology) セキュリティコンポーネントを非推奨化 (deprecate) する正式な通知を発表しました。3 年間の移行期間を経て、2029 年 10 月にサービスが完全に非推奨化 (fully deprecated) されます。

移行期間中、既存のデプロイメントは引き続きサポートされ、定期的なセキュリティ更新とバグ修正は提供されますが、OT 固有の新機能追加や投資は行われません。既存の顧客契約と更新は 2029 年 10 月まで履行されます。
✅ Microsoft Defender for Endpoint の Enterprise IoT 機能 (デバイス検出、脆弱性評価を含む) は今回の提供終了の対象外であり、引き続き利用可能です。

アップデート前後の変化

❌ Before (アップデート前)

  • Microsoft Defender for IoT の OT セキュリティコンポーネントが、OT ネットワークの脅威検出・資産可視化の Microsoft ファーストパーティソリューションとして提供されていた

✅ After (アップデート後)

  • OT セキュリティコンポーネントは 2029 年 10 月に完全非推奨化されるため、顧客は移行期間 (3 年間) 内に代替の OT セキュリティソリューションへの移行が必要
  • Microsoft は特定の代替製品を指定しないが、Microsoft Security Exposure Management の OT データコネクタ (Armis、Dragos、Forescout) により、サードパーティ OT プラットフォームの資産・脆弱性データを Defender ポータルに取り込む統合パスを提供

🔀 移行先の選択肢

Microsoft は特定の代替製品を義務付けていませんが、以下の 3 つのサードパーティプロバイダー向けに OT データコネクタを提供しています。

プロバイダー統合方法
ArmisMicrosoft Security Exposure Management の OT データコネクタ
Dragos同上
Forescout同上

これらの OT データコネクタにより、サードパーティ OT プラットフォームから以下のデータを Defender ポータルに取り込めます。

🏷️ OT デバイス・資産情報 (ホスト名、IP/MAC アドレス、シリアル番号などの識別子) 🔧 デバイスタイプ、ベンダー、モデル、ファームウェア、OS の詳細 📍 ロケーション、ゾーン、サイト、センサー、ネットワーク関連情報 ⚖️ 資産のクリティカリティ (重要度) 🐞 OT デバイスに関連する脆弱性の検出結果
これにより、IT / IoT / OT デバイスを単一のインベントリで可視化し、CVE 検索や影響範囲の調査を Defender ポータル上で横断的に行えます。
⚠️ サードパーティソリューションには別途ライセンス契約とデプロイメントが必要です。また、コネクタが提供されている 3 社以外の OT セキュリティプロバイダーを選択することも可能です。

📝 まとめ

Microsoft Defender for IoT の OT セキュリティコンポーネントが 2029 年 10 月に完全非推奨化されることが正式に発表されました。3 年間という比較的長い移行期間が設けられており、期間中はセキュリティ更新とバグ修正が継続されますが、新機能の追加はありません。

OT セキュリティを Defender for IoT で運用している組織は、早期に環境の棚卸しと移行先の選定に着手すべきです。Microsoft は Armis、Dragos、Forescout との統合コネクタを Exposure Management で提供しており、移行後も Defender ポータルでの IT / OT 横断の可視化を維持できます。Enterprise IoT 機能 (Defender for Endpoint) は対象外である点にも留意してください。
