# Azure News Summary v0.2.0

*Released: 2026-03-07*

---

## English

### 🚀 What's New

This release improves index generation for reports and infographics, and fixes CI secrets handling.

### 📝 Changes

#### Added
- ✨ Improved index generation for reports and infographics

#### Changed
- 🔄 Removed static `index.html` generation from workflow
- 🔄 Removed `INDEX.md`

#### Fixed
- 🐛 Use `secrets` instead of `vars` for `AWS_ROLE_ARN` in CI configuration
