# Azure News Summary v0.1.0

*Released: 2026-03-03*

---

## English

### 🚀 What's New

Initial release of Azure News Summary — a Claude Agent SDK skill that collects Microsoft Azure news and generates detailed Japanese reports.

### ✨ Features

- **Report Generation Skill**: Collects Azure news and generates detailed Japanese reports with the Claude Agent SDK
- **Env-based Bedrock Integration**: Replaced boto3 with environment-variable-based Bedrock integration
- **IAM Policy for Inference Profiles**: Added inference-profile permission to the Bedrock IAM policy

### 📝 Changes

#### Added
- ✨ Initial project setup (skill definition, orchestrator, parsers, CI/CD)

#### Changed
- 🔄 Replaced boto3 with env-based Bedrock integration
- 🛠️ Added inference-profile permission for Bedrock IAM policy

#### Fixed
- 🐛 Configure git user identity in CI environment
- 📝 Removed placeholder related projects section from README
